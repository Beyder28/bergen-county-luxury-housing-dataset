# Bergen County Luxury Housing Dataset

Quarterly closed-sales statistics for luxury and all-single-family segments in Alpine, Tenafly, and Saddle River, NJ. Source: NJMLS closed sales, 234 source records, 159 published rows with small-n cells suppressed per the manifest rules.

Current edition: 2026-Q3 v1 (published Oct 2026)

## Headline figures — Q3 2026

- Tenafly luxury Q3 2026 median $4,150,000 (n=9)
- Saddle River luxury Q3 2026 median $5,200,000 (n=5)
- Tenafly all-single-family Q3 2026: 36 sales, median $1,828,000
